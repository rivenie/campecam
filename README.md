# CAMPECAM — Landing page

Sitio web de una sola página de la **Cámara Peruana de Conciliación, Arbitraje y Mediación (CAMPECAM)**.

Es HTML, CSS y JavaScript puro: no necesita instalar nada ni compilar.

## Estructura

```
index.html        → la página completa (estilos y scripts incluidos)
img/              → logo y fotografías
```

## Publicar con GitHub Pages

1. Crea un repositorio nuevo en GitHub (por ejemplo `campecam-web`).
2. Sube **todo el contenido** de esta carpeta (`index.html`, `README.md` y la carpeta `img/`) a la raíz del repositorio.
3. Ve a **Settings → Pages**.
4. En **Source** elige **Deploy from a branch**, rama `main`, carpeta `/ (root)` y guarda.
5. En 1–2 minutos el sitio estará en `https://TU-USUARIO.github.io/campecam-web/`.

Para usar un dominio propio, escríbelo en **Settings → Pages → Custom domain** y apunta el DNS del dominio a GitHub Pages.

## Editar contenido

- **Textos:** se editan directamente en `index.html`.
- **WhatsApp:** los botones usan `https://wa.me/51998774832` con un mensaje prellenado según el servicio.
- **Fotos:** reemplaza los archivos de `img/` manteniendo el mismo nombre (formato `.jpg`; se recomienda un mínimo de 1200 px de ancho para la portada y 800 px para las tarjetas).
